# Bubsy in: Claws Encounters of the Furred Kind (SNES) Disassembly
Disassembly of Bubsy in: Claws Encounters of the Furred Kind (This is based off of the original ROM file with the MD5 of 6ac508bddbabc699f181d7858ccfcf0f. The ROMs from Bubsy Two-Fur and Bubsy: The Purrfect Collection are modified to remove all mentions of Nintendo.)

Help is appreciated!!! (if you have a basic understanding of DiztinGUIsh and bsnes-plus then you can contribute)

made with https://github.com/DizTools/DiztinGUIsh (I've really gotta learn how to disassemble games myself.)
